SBoM Scanner

Drop in a software bill of materials (CycloneDX or SPDX JSON). Every package is checked against the OSV.dev vulnerability database, and service inventories show credential age and blast radius. Your file never leaves the browser; only package names and versions are sent to OSV.

Drop an SBOM file here

sbom.cdx.json, bom.json, *.spdx.json

Vulnerability data: OSV.dev (GitHub Advisories, PyPA, Go, RustSec and more). Severity from the advisory, or computed from its CVSS v3 vector. Service SBoMs are produced by the sbom CLI from a Stripe Projects stack; no secret values are ever included.
